## 组件说明

### 1. PHP Laravel Web 应用

| 功能 | 端口 | 说明 |
|------|------|------|
| 前端商城 | 80 | 商品展示、下单、支付 |
| 管理后台 | /admin | DCAT Admin 后台 |
| API 接口 | /api/* | RESTful API |
| 支付网关 | /pay/* | 支付回调处理 |

### 2. Node.js Telegram Bot

| 功能 | 说明 |
|------|------|
| 区块链监控 | 实时扫描 TRC/ERC/BSC/OKC/POL/GRC 区块 |
| 合约交互 | 调用智能合约转账 |
| Telegram 命令 | 处理群组消息和指令 |
| 自动分润 | 阈值触发自动转账并按比例分润 |

### 3. 数据库

#### 核心业务表
- `goods` — 商品
- `goods_group` — 商品分类
- `carmis` — 卡密库存
- `orders` — 订单
- `coupons` — 优惠券
- `pays` — 支付配置
- `emailtpls` — 邮件模板

#### 扩展功能表
- `fish` — 钱包地址管理
- `fish_browse` — 浏览播报记录
- `daili` — 代理管理
- `daili_group` — 代理分组
- `options` — 系统配置
- `system_settings` — 站点设置

## 支付流程

```
用户下单 → 选择支付方式 → 跳转网关
  → 支付完成 → 回调验证 → 自动/手动发货
  → 邮件通知 → 推送通知（Telegram/Bark/企业微信等）
```

## 订单状态流转

```
待支付(1) → 待处理(2) → 处理中(3) → 已完成(4)
                         ↘ 失败(5)
              ↘ 超时 → 过期(-1)
```
